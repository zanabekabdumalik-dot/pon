# 📡 nmap

⚖️ Сканируй только свои виртуалки и машины учебных площадок, к которым
подключён по их VPN.

| Команда | Что делает |
|---|---|
| `nmap 10.10.10.10` | Топ-1000 TCP-портов |
| `nmap -p- --min-rate 1000 10.10.10.10` | Все 65535 TCP-портов, быстрее |
| `nmap -sC -sV -p 22,80,445 10.10.10.10` | Скрипты по умолчанию + версии на найденных портах |
| `sudo nmap -sU --top-ports 50 10.10.10.10` | Топ-50 UDP-портов (медленно) |
| `nmap -Pn ...` | Не проверять «жив ли хост» (если он не отвечает на ping) |
| `nmap -oA scans/имя ...` | Сохранить результат во всех форматах |
| `nmap --script vuln -p 80 10.10.10.10` | Скрипты поиска известных уязвимостей |
| `ls /usr/share/nmap/scripts/ \| grep smb` | Какие скрипты есть для сервиса |

## Рабочий порядок на учебной машине

```bash
mkdir -p scans
nmap -p- --min-rate 1000 -oA scans/all 10.10.10.10
nmap -sC -sV -p <порты_из_первого_скана> -oA scans/detail 10.10.10.10
```
