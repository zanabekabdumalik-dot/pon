# 📓 Дневник

Каждый учебный день — один файл с датой в названии, например `2026-11-06.md`.
Создавай его из шаблона `День` (`Ctrl+P` → **Templates: Insert template**).

5–10 минут записи в конце дня — и через месяц ты увидишь, какой путь прошёл,
а через полгода у тебя будет готовый материал для блога и собеседований.
