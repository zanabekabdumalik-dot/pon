# 🐍 Python

**Цель этапа:** не стать разработчиком, а уметь быстро написать скрипт,
который автоматизирует рутину или прочитать чужой эксплойт и понять его.

Основной учебник: **«Automate the Boring Stuff with Python»** (бесплатно онлайн).

## 🛠️ Мини-проекты

Запускай только против своих виртуалок, `127.0.0.1` или учебных машин.

- [ ] **Сканер портов** на `socket`: принимает IP и диапазон портов, выводит открытые.
- [ ] **Поиск директорий**: берёт список слов из SecLists, перебирает пути на
      учебной машине через `requests`, выводит те, что не 404.
- [ ] **Подбор хэша**: берёт MD5/SHA-256-хэш и словарь, находит исходное слово
      (`hashlib`). Пойми, почему соль ломает этот подход.
- [ ] **Парсер логов**: читает лог веб-сервера, считает IP-адреса с наибольшим
      числом ошибок 404 (так защитники ищут сканеры).
- [ ] **Декодер**: автоматически определяет и декодирует base64 / hex / rot13.

Код складывай в репозиторий на GitHub — это часть портфолио.
