[Bandit](Bandit.md), справка — `man команда` и `команда --help`.

## Шпаргалка

### Навигация и файлы
| Команда | Что делает |
|---|---|
| `pwd` | Где я сейчас |
| `ls -la` | Все файлы, включая скрытые, с правами |
| `cd /путь`, `cd ..`, `cd ~` | Перейти / вверх / домой |
| `cat`, `less`, `head -n 20`, `tail -f` | Показать файл / листать / начало / следить за концом |
| `cp`, `mv`, `rm`, `mkdir -p` | Копировать / переместить / удалить / создать папки |
| `file имя` | Определить тип файла по содержимому |

### Поиск
| Команда | Что делает |
|---|---|
| `find / -name "*.conf" 2>/dev/null` | Найти файлы по имени, скрыть ошибки |
| `find . -type f -size 1033c` | Найти файл ровно 1033 байта |
| `grep -rni "password" .` | Искать текст во всех файлах, без учёта регистра |
| `which`, `whereis` | Где лежит программа |

### Права
| Команда | Что делает |
|---|---|
| `chmod 755 файл` | rwx для владельца, r-x для остальных |
| `chmod +x скрипт.sh` | Сделать исполняемым |
| `chown user:group файл` | Сменить владельца |
| `id`, `whoami`, `groups` | Кто я и в каких группах |
| `sudo -l` | Что мне разрешено через sudo (пригодится в privesc!) |

### Процессы и сеть
| Команда | Что делает |
|---|---|
| `ps aux`, `top`/`htop` | Процессы |
| `kill PID` | Завершить процесс |
| `ss -tulpn` | Какие порты слушаются |
| `ip a` | Мои IP-адреса |
| `curl -i http://...` | HTTP-запрос с заголовками ответа |
| `ssh user@host -p порт` | Подключиться по SSH |

### Связки
| Синтаксис | Что делает |
|---|---|
| `a \| b` | Вывод a → на вход b |
| `> файл`, `>> файл` | Записать / дописать вывод в файл |
| `2>/dev/null` | Выкинуть ошибки |
| `sort \| uniq -c` | Посчитать повторы |
| `base64 -d`, `xxd`, `tr` | Декодирование и преобразования (будут в Bandit) |
