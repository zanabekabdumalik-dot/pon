# 🏢 Пентест инфраструктуры (лето после УБТ)

Методология — в [шпаргалке](../Шпаргалки/Методология.md), команды nmap —
в [nmap](../Шпаргалки/nmap.md).

## Разведка и перечисление
- [ ] nmap: все TCP-порты, версии, скрипты, топ UDP
- [ ] HTTP: технологии, директории, виртуальные хосты
- [ ] SMB: общие папки, анонимный доступ (`smbclient`, `netexec`)
- [ ] FTP / SSH / SMTP / SNMP: что можно узнать без пароля
- [ ] Поиск публичных эксплойтов: `searchsploit`, Exploit-DB, GitHub

## Повышение привилегий в Linux
- [ ] `sudo -l` и **GTFOBins** (<https://gtfobins.github.io>)
- [ ] SUID / SGID-файлы
- [ ] Capabilities
- [ ] Cron-задачи и записываемые скрипты
- [ ] PATH-хайджекинг
- [ ] Пароли в конфигурационных файлах и истории
- [ ] Уязвимости ядра (последнее, что проверяешь)
- [ ] Автоматизация: **LinPEAS** — но сначала научись вручную

## Повышение привилегий в Windows
- [ ] Привилегии токена (`whoami /priv`)
- [ ] Уязвимые службы и права на них
- [ ] Пути без кавычек (unquoted service path)
- [ ] Запланированные задачи
- [ ] Сохранённые учётные данные, реестр
- [ ] **LOLBAS** (<https://lolbas-project.github.io>), **WinPEAS**

## Active Directory
- [ ] Что такое домен, контроллер домена, Kerberos, LDAP
- [ ] Перечисление пользователей и групп
- [ ] AS-REP Roasting, Kerberoasting
- [ ] Pass-the-Hash, Pass-the-Ticket
- [ ] **BloodHound** — пути атаки на графе
- [ ] Своя AD-лаборатория дома (Windows Server Evaluation в VirtualBox) — по желанию
