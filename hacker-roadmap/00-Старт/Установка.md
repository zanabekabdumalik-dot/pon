# 🧰 Установка рабочего места

Займёт 1–1.5 часа. Это твой первый практический урок — делай сам и
записывай в дневник, что пошло не так и как ты это решил.

## Что нужно от компьютера

| | Минимум | Комфортно |
|---|---|---|
| Оперативная память | 8 ГБ | 16 ГБ |
| Свободное место | 60 ГБ | 100+ ГБ (лучше SSD) |
| Процессор | 4 потока, поддержка VT-x / AMD-V | 8+ потоков |

> 💡 Слабый компьютер (меньше 8 ГБ)? Не страшно: на старте используй
> **AttackBox** в TryHackMe и **Pwnbox** в HackTheBox — это Kali прямо в
> браузере. Виртуалку поставишь позже.

## Шаг 1. Включить виртуализацию

1. Проверь: Windows → `Ctrl+Shift+Esc` → **Производительность → ЦП** →
   строка **«Виртуализация: Включено»**.
2. Если «Отключено» — перезагрузись в BIOS/UEFI (обычно `Del`, `F2` или `F10`
   при старте), найди **Intel Virtualization Technology (VT-x)** или
   **SVM Mode (AMD)** → Enabled → сохрани.

## Шаг 2. VirtualBox

1. Скачай с <https://www.virtualbox.org/wiki/Downloads> версию для своей ОС.
2. Установи с настройками по умолчанию.
3. Если Windows пишет про Hyper-V/конфликты — запиши ошибку в дневник и
   погугли её дословно. Это нормальная часть процесса.

**Mac на Apple Silicon (M1–M4):** VirtualBox не подходит — ставь **UTM**
(<https://mac.getutm.app>) или VMware Fusion и **ARM-версию** Kali.

## Шаг 3. Kali Linux

Проще всего — готовый образ виртуальной машины:

1. <https://www.kali.org/get-kali/#kali-virtual-machines> → **VirtualBox**.
2. Распакуй архив `.7z` программой **7-Zip**.
3. Дважды кликни файл `.vbox` — машина появится в VirtualBox.
4. Настройки машины: **ОЗУ** — половина от твоей (но не больше 8 ГБ),
   **процессоры** — 2–4.
5. Запусти. Логин и пароль по умолчанию: `kali` / `kali`.

## Шаг 4. Первая настройка Kali

Открой терминал в Kali и выполни:

```bash
passwd
```

(смени стандартный пароль — первое правило безопасности)

Затем скачай и запусти скрипт из этой папки — он обновит систему,
доставит инструменты и создаст папки для лаб:

```bash
bash setup-kali.sh
```

Файл [setup-kali.sh](setup-kali.sh) можно скопировать в виртуалку через
общую папку VirtualBox или просто открыть его на GitHub и переписать
руками — заодно разберёшься, что делает каждая строка.

## Шаг 5. Снимок системы

VirtualBox → выбери машину → **Снимки (Snapshots) → Сделать** →
назови «чистая система». Если что-то сломаешь — откатишься за минуту.

## Шаг 6. Obsidian

1. <https://obsidian.md> → установить (на основной компьютер, не в Kali).
2. **Open folder as vault** → папка `hacker-roadmap`.
3. Включи шаблоны — инструкция в [README](../README.md).

## Шаг 7. VPN для лабораторий

TryHackMe и HackTheBox дают файл `.ovpn` — он подключает Kali к их
учебной сети. Скачай его на сайте (раздел Access / Connect) и запусти:

```bash
sudo openvpn ~/Downloads/имя-файла.ovpn
```

Окно терминала не закрывай, пока работаешь с машинами.
