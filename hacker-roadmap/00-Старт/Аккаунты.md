# 🔑 Аккаунты

## Сначала — гигиена (это уже кибербезопасность)

1. **Менеджер паролей** — Bitwarden (<https://bitwarden.com>, бесплатно).
   Один сильный мастер-пароль, остальные пароли генерирует он, все разные.
2. **Отдельная почта** для учёбы и ИБ-площадок (по желанию, но удобно).
3. **Двухфакторная аутентификация (2FA)** — везде, где есть. Приложение:
   Aegis (Android), Raivo/2FAS (iPhone) или встроенное в Bitwarden.
4. **Один ник везде.** Это твой будущий бренд: рейтинги HTB, CTF и разборы
   на GitHub будут собираться под одним именем.

> 🚫 Никому не отправляй пароли — ни друзьям, ни «техподдержке», ни ИИ.
> Просьба «дай пароль, я всё настрою» — классика социальной инженерии.
