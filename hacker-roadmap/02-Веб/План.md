# 🕸️ Веб-безопасность (месяцы 3–4)

**Главный ресурс:** PortSwigger Web Security Academy —
<https://portswigger.net/web-security/all-topics>. Бесплатно, лучшие лабы в мире.

**Как проходить тему:** прочитать теорию → пройти все лабы **Apprentice** →
заполнить заметку по шаблону `Уязвимость` → вернуться к уровню **Practitioner**
на этапе 4, если выберешь веб.

## Инструменты
- [ ] **Burp Suite**: Proxy (перехват), Repeater (повтор запросов), Intruder,
      Decoder, Comparer — разобраться на первых лабах
- [ ] Браузерное расширение FoxyProxy для переключения на Burp
- [ ] `ffuf` / `gobuster` — поиск скрытых директорий и параметров
- [ ] `sqlmap` — только **после** того, как умеешь находить SQLi руками
