3 часа подготовки к УБТ в день), конспекты по этапам, шаблоны и шпаргалки.

> (TryHackMe, HackTheBox, PortSwigger, CTF). Атака на чужие системы без
> письменного разрешения — уголовная статья.

## Как открыть в Obsidian

1. Скачай репозиторий: на GitHub → **Code → Download ZIP**, распакуй
   (или `git clone`, если уже умеешь — скоро научишься).
2. Установи Obsidian: <https://obsidian.md>.
3. **Open folder as vault** → выбери папку `hacker-roadmap`.
4. Включи шаблоны: **Settings → Core plugins → Templates** (вкл.), затем
   **Settings → Templates → Template folder location** → `Шаблоны`.
5. Новая запись дня: создай файл в `Дневник/` с датой в названии
   (например `2026-11-06`) → `Ctrl+P` → **Templates: Insert template** → `День`.

## Главное правило конспектов

Заметки, которые написал **ты сам своими словами**, работают в разы лучше
чужих. Здесь — каркас и вопросы, ответы на которые ты впишешь сам.
Где видишь `✍️` — это место для твоего текста.

🔒 Никогда не записывай сюда пароли от своих аккаунтов. Если репозиторий
публичный — пароли уровней Bandit и флаги активных машин тоже не коммить.
