# 100 фобий — мультики для YouTube Shorts

## Выпуск №2 — талассофобия (страх глубины)

Готовый ролик: [`ep02/out/fobiya-02-talassofobiya.mp4`](ep02/out/fobiya-02-talassofobiya.mp4)
— 1080×1920, 30 к/с, 56 с, H.264 + AAC, −16 LUFS. Озвучка — голос `ru_RU-denis-medium`
(датасет CC0, монетизировать можно).

Формат «спуск на глубину со счётчиком» выбран по данным NexLev: анимированный Short
«Walking to Challenger Deep» набрал 4,4 млн просмотров на канале с 12 тыс. подписчиков,
а русскоязычные ролики про талассофобию — в основном нарезки фото с десятками просмотров.
Ниша пустая, формат проверенный.

Петя в батискафе спускается на дно Марианской впадины. Счётчик глубины останавливается на каждой
отметке ровно к реплике: 40 м — предел для дайверов-любителей, 200 м — кончается солнечный свет,
332 м — рекорд с аквалангом, 1 000 м — вечная ночь и удильщик, 2 000 м — кашалот с гигантским
кальмаром, 3 800 м — «Титаник», 6 000 м — зона Аида (стены впадины и глаза в темноте),
8 336 м — самая глубокая рыба, которую удалось снять, 10 935 м — дно. Затем давление
(трещины на стекле, «1 т на 1 см²») и разрез впадины с Эверестом, вершина которого остаётся
на 2 км под водой. В конце — вопрос «на какой глубине стало не по себе?», чтобы писали комментарии.

Удержание: хук-вызов «Досмотришь до дна — значит, у тебя нет талассофобии», огромная тень кита
под батискафом в первом кадре, счётчик и полоска «до дна» слева, которые тянут досмотреть до конца.

## Выпуск №1 — гиппопотомонстросесквиппедалиофобия (боязнь длинных слов)

Готовый ролик: [`ep01/out/fobiya-01-boyazn-dlinnyh-slov.mp4`](ep01/out/fobiya-01-boyazn-dlinnyh-slov.mp4)
— вертикальное видео 1080×1920, 30 к/с, 50 с, H.264 + AAC. Озвучка — низкий спокойный мужской голос
«Руслан», читает слитно, без склеек; громкость −16 LUFS (чуть тише стандартных −14).

> ⚠️ Голос `ru_RU-ruslan-medium` обучен на корпусе RUSLAN с лицензией CC BY-NC-SA 4.0 —
> некоммерческое использование. Для монетизируемого канала переключите `voice` в `script.json`
> на `ru_RU-dmitri-medium` / `ru_RU-denis-medium` (CC0) и пересоберите.

Герой — Петя, который боится длинных слов. Сюжет: короткие слова Петя любит → падает
«ДОСТОПРИМЕЧАТЕЛЬНОСТЬ» → барабанная дробь → название фобии из 35 букв → Петя в обмороке →
разбор, из чего сложено слово → короткий вариант «сесквипедалофобия» → призыв написать в комментариях.

### Как устроено

| Файл | Что делает |
|---|---|
| `ep01/script.json` | Текст озвучки по репликам, голос, темп (`length_scale`), обработка голоса (`voice_fx`); `pause` у реплики — жёсткая пауза и конец слитного абзаца |
| `ep01/tts.py` | Озвучка голосом [Piper](https://github.com/rhasspy/piper): абзац синтезируется за один проход (слитная речь), границы фраз — по паузам в записи; обработка тембра по `voice_fx`; тайминги фраз и слов → `build/timeline.json` |
| `ep01/anim.html` | Вся анимация на canvas; кадр — функция от времени, сцены привязаны к таймингам реплик |
| `ep01/render.js` | Покадровый рендер в headless Chromium → `build/video.mp4` и метки звуков `build/cues.json` |
| `ep01/audio.py` | Музыка и звуковые эффекты, синтезированные кодом, сведение с голосом и приглушение под речью |
| `ep01/mux.py` | Склейка видео и звука, нормализация громкости |

Музыка и эффекты сгенерированы с нуля, чужих сэмплов нет — Content ID не сработает.

### Пересборка

```bash
cd ep01
pip install piper-tts numpy scipy
./build.sh              # скачает голос, поставит npm-зависимости и соберёт out/*.mp4
```

Нужны ffmpeg и Chromium (путь можно задать через `CHROMIUM=/path/to/chrome`).
Посмотреть анимацию в браузере без рендера: открыть `anim.html?preview` через локальный сервер
после `python3 tts.py`.

Голос меняется в `script.json` (`voice`): подходят модели Piper из
[зеркала sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models) —
`ru_RU-irina-medium` (женский), `ru_RU-dmitri-medium` и `ru_RU-denis-medium` (мужские, CC0).
`ru_RU-ruslan-medium` звучит низко и красиво, но его лицензия (CC BY-NC-SA) запрещает монетизацию.

Для следующего выпуска достаточно скопировать `ep01`, переписать `script.json` и сцены в `anim.html`.
