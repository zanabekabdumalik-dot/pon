# 100 фобий — мультики для YouTube Shorts

## Выпуск №1 — гиппопотомонстросесквиппедалиофобия (боязнь длинных слов)

Готовый ролик: [`ep01/out/fobiya-01-boyazn-dlinnyh-slov.mp4`](ep01/out/fobiya-01-boyazn-dlinnyh-slov.mp4)
— вертикальное видео 1080×1920, 30 к/с, 50 с, H.264 + AAC. Озвучка — низкий спокойный мужской голос
«Руслан», читает слитно, без склеек; громкость −16 LUFS (чуть тише стандартных −14).

> ⚠️ Голос `ru_RU-ruslan-medium` обучен на корпусе RUSLAN с лицензией CC BY-NC-SA 4.0 —
> некоммерческое использование. Для монетизируемого канала переключите `voice` в `script.json`
> на `ru_RU-dmitri-medium` / `ru_RU-denis-medium` (CC0) и пересоберите.

Герой — Петя, который боится длинных слов. Сюжет: короткие слова Петя любит → падает
«ДОСТОПРИМЕЧАТЕЛЬНОСТЬ» → барабанная дробь → название фобии из 35 букв → Петя в обмороке →
разбор, из чего сложено слово → короткий вариант «сесквипедалофобия» → призыв написать в комментариях.

### Как устроено

| Файл | Что делает |
|---|---|
| `ep01/script.json` | Текст озвучки по репликам, голос, темп (`length_scale`), обработка голоса (`voice_fx`); `pause` у реплики — жёсткая пауза и конец слитного абзаца |
| `ep01/tts.py` | Озвучка голосом [Piper](https://github.com/rhasspy/piper): абзац синтезируется за один проход (слитная речь), границы фраз — по паузам в записи; обработка тембра по `voice_fx`; тайминги фраз и слов → `build/timeline.json` |
| `ep01/anim.html` | Вся анимация на canvas; кадр — функция от времени, сцены привязаны к таймингам реплик |
| `ep01/render.js` | Покадровый рендер в headless Chromium → `build/video.mp4` и метки звуков `build/cues.json` |
| `ep01/audio.py` | Музыка и звуковые эффекты, синтезированные кодом, сведение с голосом и приглушение под речью |
| `ep01/mux.py` | Склейка видео и звука, нормализация громкости |

Музыка и эффекты сгенерированы с нуля, чужих сэмплов нет — Content ID не сработает.

### Пересборка

```bash
cd ep01
pip install piper-tts numpy scipy
./build.sh              # скачает голос, поставит npm-зависимости и соберёт out/*.mp4
```

Нужны ffmpeg и Chromium (путь можно задать через `CHROMIUM=/path/to/chrome`).
Посмотреть анимацию в браузере без рендера: открыть `anim.html?preview` через локальный сервер
после `python3 tts.py`.

Голос меняется в `script.json` (`voice`): подходят модели Piper из
[зеркала sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models) —
`ru_RU-irina-medium` (женский), `ru_RU-dmitri-medium` и `ru_RU-denis-medium` (мужские, CC0).
`ru_RU-ruslan-medium` звучит низко и красиво, но его лицензия (CC BY-NC-SA) запрещает монетизацию.

Для следующего выпуска достаточно скопировать `ep01`, переписать `script.json` и сцены в `anim.html`.

# Мой говорящий Гаппо — игра

Бегемотик Гаппо, за которым нужно ухаживать, как за Томом из «Моего говорящего Тома».
Вся игра — один файл [`gappo/index.html`](gappo/index.html): рисунки на canvas, звуки синтезируются кодом,
чужих картинок и сэмплов нет.

**APK для Android:** [`gappo/out/gappo.apk`](gappo/out/gappo.apk) — скачать на телефон, разрешить установку
из неизвестных источников и установить. Android 7.0 и новее, работает без интернета.

### Что умеет Гаппо

- **Повторяет за тобой.** Нажми на микрофон и скажи фразу — Гаппо прислушается и повторит её писклявым
  голосом. Можно и написать текст (кнопка с облачком): Гаппо прочитает его высоким голосом.
- **Своё лицо.** Гардероб → «Лицо» → «Загрузить фото»: выбери фото, подвинь лицо в овал и отметь, где рот.
  Когда Гаппо говорит, «челюсть» на фото открывается. Фото хранится только на телефоне.
- **Четыре потребности:** еда, сон, чистота, радость. Они понемногу тают, даже когда игра закрыта.
- **Комнаты:** кухня (7 видов еды, перчик жжётся, пломбир морозит), ванная (мыло, душ, резиновая уточка),
  спальня (выключи свет — Гаппо уснёт), двор (мячик и мини-игра «Фруктопад»).
- **Реакции на касания:** погладь голову, пощекочи живот, нажми на нос — чихнёт, по голове — «Ой!».
- **Монетки, уровни, подарок дня, гардероб:** 7 расцветок и 7 шапок, включая ушанку и корону.

### Как устроен APK

| Файл | Что делает |
|---|---|
| `gappo/android/src/.../MainActivity.java` | WebView с игрой по адресу `https://appassets.androidplatform.net/` (нужен для микрофона), разрешение на микрофон, выбор фото, системный синтез речи, кнопка «Назад» |
| `gappo/android/AndroidManifest.xml` | Манифест: портретный экран, микрофон, Android 7.0+ |
| `gappo/android/tools/build_apk.py` | Замена aapt2: кодирует манифест и иконку в бинарный формат Android, пишет `resources.arsc`, собирает zip |
| `gappo/android/tools/Sign.java` | Подпись схемой v2 через `apksig` и проверка подписи |
| `gappo/android/tools/render_icons.js` | Рисует иконку приложения тем же кодом, что и Гаппо |
| `gappo/android/build.sh` | Всё вместе |

Пересборка (нужны JDK 17+, Python 3 и Node.js, Android SDK не нужен — инструменты качаются с Maven Central):

```bash
cd gappo/android
./build.sh              # → gappo/out/gappo.apk
node tools/render_icons.js   # перерисовать иконку (нужен Playwright)
```

`debug.keystore` — отладочный ключ (пароль `android`), чтобы новые сборки ставились поверх старой без
потери прогресса. Для публикации в Google Play нужен свой ключ и targetSdk 35.

В браузере игру можно открыть через локальный сервер (`npx http-server` в корне и
`http://localhost:8080/gappo/`): микрофон работает только по `https://` или на `localhost`.
