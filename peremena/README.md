# «Перемена» — фокус-таймер, который заботится о здоровье

Школьный проект, 11 класс («Build it. Test it. Improve it.»).

**Проблема.** Старшеклассники сидят за учёбой по многу часов подряд, а перерывы проводят в телефоне.
Устают глаза, затекают шея и спина, падает концентрация, не хватает сна.

**Решение.** Веб-приложение, которое делит учёбу на «уроки» и «перемены» и превращает перемену
в короткую разминку на 2–3 минуты.

## Функции

1. **Фокус-таймер** — режимы 45/10 («как в школе»), 25/5 («помодоро»), 15/3 и свой; школьный звонок в конце.
2. **Разминка на перемене** — 4 упражнения: глаза (правило 20-20-20), шея, спина, дыхание; анимация и таймер на каждое.
3. **Калькулятор сна** — во сколько лечь, чтобы спать 8–10 часов (норма для 13–18 лет по AASM).
4. **Прогресс** — баллы, уровни, серия дней, график за неделю и награды.

Ещё: русский и английский язык, светлая тема («тетрадь в клетку») и тёмная («школьная доска»),
демо-режим для защиты (минута урока идёт за секунду). Данные хранятся только в браузере
(`localStorage`) и никуда не отправляются.

## Файлы

| Файл | Что это |
|---|---|
| `app.html` | Исходник приложения (HTML + CSS + JS в одном файле, без библиотек) |
| `index.html` | Готовая страница: открывается двойным щелчком в любом браузере. Собирается из `app.html` командой `./build.sh` |
| `pitch/` | Резервная копия слайдов для защиты (5 слайдов, формат Slides) |
| `tests/e2e.js` | 43 автоматические проверки в браузере (Playwright): таймер, разминка, сохранение, ошибки ввода, ширина телефона, английский язык |

## Запуск тестов

```bash
./build.sh
node tests/e2e.js            # нужен установленный playwright
```
